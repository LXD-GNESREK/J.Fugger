# Ledgerly

Ledgerly ist ein Expense-Tracker Software für ein Unternehmen. Der Schwerpunkt des Projekts liegt auf Security.

Gruppenprojekt im Rahmen der Lehrveranstaltung zu Web-Security an der FH Technikum Wien.
